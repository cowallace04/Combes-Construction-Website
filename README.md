# Combes Construction Website

Custom WordPress website for Combes Construction, LLC.

## Environments

- Development: Local WordPress / WordPress Playground
- Staging: SiteGround staging
- Production: SiteGround production

## Repository structure

- `docs`: Requirements, sitemap and implementation documentation
- `design`: Brand assets, wireframes and visual references
- `content`: Source content for pages, projects, team and careers
- `wordpress`: Custom WordPress theme and plugin source code

## WordPress components

- Theme: `combes-construction`
- Core plugin: `combes-core`
