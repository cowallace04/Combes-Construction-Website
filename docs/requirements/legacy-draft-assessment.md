# Legacy Draft Website Assessment

## Source

The previous website draft was built from the ConstructZilla commercial
construction HTML template. The recovered Word document contains HTML, CSS,
JavaScript and references to site assets.

## Purpose

The legacy draft is reference material only. It is not the technical foundation
for the new WordPress website.

## Concepts to Retain

- Horizontal desktop navigation
- Sticky header
- White logo treatment over dark or blue backgrounds
- Project image tiles
- Project-image hover treatment
- Team-member grid
- Contact information in the footer
- Responsive mobile navigation
- Project photo galleries

## Concepts to Replace

- White primary background
- Yellow dominant accent color
- Roboto and Open Sans typography
- Angular and skewed template decorations
- Revolution Slider
- Generic template copy
- Employee social-media overlays
- Static HTML content management
- Large collection of global jQuery plugins

## Potential Recoverable Assets

- White Combes logo files
- Team names and positions
- Team photographs
- Project names
- Project photographs
- Contact information
- Existing written content

All recovered information and assets must be verified before reuse.

## Technical Direction

The new site will use:

- A custom WordPress block theme
- A separate Combes core plugin for structured business content
- Barlow headings
- Source Sans 3 body text
- The approved dark-blue color system
- Native WordPress functionality where practical
- Modern CSS layouts
- Minimal JavaScript
- Purpose-specific dependencies only when necessary

## Licensing Rule

Do not copy template code, imagery, fonts, icons or commercial assets into the
new repository until ownership and reuse rights have been confirmed.
