# Combes Construction Color System

## Brand Blues

- Primary Blue: `#014E8B`
- Secondary Blue: `#1F4D9E`
- Accent Blue: `#346FA2`
- Soft Blue: `#AEC5D7`

## Accessible Link Blues

- Link: `#79B8E8`
- Link Hover: `#AECBE0`

## Backgrounds and Surfaces

- Base Background: `#050814`
- Section Background: `#082745`
- Card Surface: `#111827`
- Alternate Surface: `#1F2933`

## Text

- Primary Text: `#F9FAFB`
- Muted Text: `#D0D2D4`
- Text on Blue: `#FFFFFF`

## Borders

- Subtle Border: `#46515F`
- Strong Border: `#738091`

## Utility Colors

- Success: `#22C55E`
- Warning: `#FACC15`
- Error: `#F97373`

## Usage Rules

- Primary and Secondary Blue are surface and action colors, not ordinary text colors on the base background.
- Use Link Blue for inline links on dark backgrounds.
- Use Soft Blue for footer links, small highlights and restrained accents.
- Use Warning Yellow only for meaningful warnings, bid deadlines or status indicators.
- Use Primary Text for body copy.
- Use Muted Text for metadata and secondary information.
